# Bike Sales Dashboard In Excel

### Project Overview

This project involves analyzing a bike sales dataset to uncover insights into customer purchasing behaviors. Utilizing Microsoft Excel, the project encompasses data cleaning, transformation, analysis through pivot tables, and the creation of an interactive dashboard. The primary objective is to identify key factors influencing bike purchases, such as income levels, commute distances, and age brackets.

### Objectives

- Determine the average income of bike buyers versus non-buyers.

- Analyze the relationship between customer commute distances and bike purchases.

- Examine how different age brackets correlate with bike purchasing behavior.

### Dataset

The primary dataset used for this analysis is the "Bike_Sales_Dataset_Excel_Project.xlsx" file, which includes various demographic details such as marital status, gender, income, level of education, occupation, and commute distance.

### Tools and Techniques

- Microsoft Excel: Data cleaning, pivot tables, and dashboard creation.

- Functions Used: IF, FIND & REPLACE, Auto Fill.

- Features Utilized: Pivot Tables, Pivot Charts, Slicers.

### Methodology
**1. Data Cleaning**
- Standardized categorical variables (e.g., converted 'M'/'F' to 'Male'/'Female').

- Removed duplicate entries.

- Created a new column for age brackets using nested IF functions.

**2. Data Analysis**
- Constructed pivot tables to summarize key metrics.

- Generated pivot charts to visualize relationships between variables.

**3. Dashbord Creation**
- Developed an interactive dashboard incorporating slicers for dynamic filtering.

### Dashboard Features
- Interactive Slicers: Filter data by marital status, education, and region.

- Visual Representations: Bar charts and line graphs depicting key relationships.

Pivot tables and Pivot charts


### Key Insights
1. Income Influence: Higher average income is associated with increased likelihood of purchasing a bike.
2. Commute Distance: Customers with shorter commute distances (0-1 mile) are more inclined to buy bikes.
3. Age Brackets: The 31-54 age group (Middle Age) constitutes the majority of bike purchasers.
